Supabase Configuration

🔌 Connect Live Agent Telemetry

Set these environment variables to activate real-time agent sync from all 14 agents into this dashboard.

1
Create Supabase project
Go to supabase.com → New Project → copy your project URL and anon key.
2
Run schema migration
Open SQL Editor in Supabase and paste contents of:
scripts/supabase/001_ktv_dashboard_schema.sql
3
Set environment variables
SUPABASE_URL=https://xxx.supabase.co
SUPABASE_ANON_KEY=eyJ...
SUPABASE_SERVICE_ROLE_KEY=eyJ... (optional)
4
Enable realtime
Supabase → Database → Replication → enable agent_status, team_activity, brain_decisions
5
Wire dashboard to live data
Replace SUPABASE_URL and SUPABASE_ANON_KEY in the script block below this panel to activate live polling in this HTML file.
6
Start the platform
npm run build && npm start
Agents will auto-report telemetry via AgentTelemetry class in src/integrations/supabase.ts
