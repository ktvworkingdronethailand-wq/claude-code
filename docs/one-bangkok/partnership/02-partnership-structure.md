## 1. The Partnership Triangle

```
ONE BANGKOK PROPERTY MANAGEMENT (Client)
            |
     IFS Platform Layer
     (FM Software + Data Hub)
        /            \
      KTV              PCS
  (Aerial Drone      (Ground-Level
   Operations)        FM Services)
```

### KTV Working Drone (Aerial Operations + Data)
- All drone-based FM: facade cleaning, inspection, solar maintenance
- Smart Green ESG telemetry from every operation
- Proprietary data pipeline converting sensor output to structured asset data
- JV structure: 50% control, IFS equity at 32M/64M/160M THB milestones

### IFS Thailand (Enterprise FM Software)
- IFS Cloud/Assyst platform for asset and facility management
- Receives drone data as structured feeds for work orders and lifecycle tracking
- Channel partner: all FM-scope work routes through IFS
- Benefits from KTV as showcase integration partner

### PCS Thailand (Ground-Level FM)
- Ground-level: cleaning, M&E maintenance, security, landscaping
- Day-to-day client relationship with One Bangkok
- Site access, safety compliance, logistics support for drone ops
- Established FM brand de-risks KTV's entry

## 2. Exclusive Deal Structure

### Scope of Exclusivity

**Included:**
- All UAV operations within One Bangkok site boundary
- Facade, window, solar panel cleaning via drone
- Structural and thermal inspection via drone
- Future drone-delivered FM services

**Excluded:**
- Manned aerial work (rope access, gondola)
- Construction-phase drone services
- Tenant-specific drone operations

### Territory

- **Phase 1:** One Bangkok site only (negotiate now)
- **Phase 2:** Right of first refusal on TCC Group portfolio
- **Phase 3:** Regional expansion (3-5 year horizon)

### Duration

**Recommended: 3+2 Year Structure**
- Initial: 3 years exclusive
- Auto-renewal: 2 additional years unless 6 months notice
- Performance review at 18 months (not a termination trigger)

### Performance Guarantees

| Guarantee | Target |
|-----------|--------|
| Service availability | 95% on-time completion |
| Safety record | Zero incidents |
| Data delivery | Reports within 48 hours |
| IFS integration uptime | 99.5% |
| ESG reporting | Quarterly on schedule |
| Emergency response | On-site within 4 hours |

## 3. PCS Collaboration Model

### Recommended: Parallel Direct Contracts

Both KTV and PCS contract directly with One Bangkok — NOT subcontracting.

### Division of Scope

| Domain | KTV | PCS |
|--------|-----|-----|
| Facade cleaning (above 6 floors) | Primary | Support |
| Solar panel cleaning | Primary | None |
| Structural inspection (exterior) | Primary | None |
| Window cleaning (interior + low-rise) | None | Primary |
| M&E inspection (accessible) | None | Primary |
| ESG data (aerial) | Primary | None |
| ESG data (ground sensors) | None | Primary |

### Coordination Terms

- PCS: 72-hour advance notice for drone operations
- KTV: 48-hour notice for ground support needs
- Joint safety briefings before concurrent operations
- KTV pays PCS 15-25K THB/month coordination fee
